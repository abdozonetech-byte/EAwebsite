PROMPT LIBRARY — ENGLISH DEFAULT AND FRENCH EDITION
28 October 2026

Implemented locally; not committed, pushed or deployed in this update.

English is the default at /prompts/ and its existing detail/guide URLs.
French remains available at /prompts/fr/ with corresponding detail/guide pages.
There are 210 unique prompt identities, each with English and French editions:
424 static pages total, not 420 different prompts.

CONTENT
- Added 210 editorial English adaptations, organised in 14 category source files
  under assets/data/prompt-english/. These include English titles, full prompts,
  named variables, illustrative examples and educational metadata.
- English explanations are requested unless the task/user needs another language.
- The original French source bodies and examples remain unchanged in the data.
- English examples are illustrative, not executed model results or research.
- No translation API, model calls, paid dependency or new database was added.

UI AND NAVIGATION
- Visible EN/FR links on the catalogue, each detail page and the learning guide.
- Switching keeps the corresponding resource and category/model/level/sort/page
  query state. Language-specific topic filters reset rather than carrying an
  incompatible label. Search text is preserved, not automatically translated.
- Detail back-to-results links are validated and use the selected language.
- Favourites retain the existing shared IDs/storage key across both languages.
- Prompts copied from cards load the appropriate static language-specific JSON.
- English navigation labels, search, filters, statuses, copy/reset controls,
  examples, guide, metadata and document language; French controls preserved.
- The rest of the website and all CRM/database functionality are unchanged.
- Existing slugs are retained to avoid breaking links; English is not forced
  across unrelated French website pages.

SEO
- Self-canonicals for each edition and reciprocal en/fr hreflang links.
- x-default points to English. Structured-data language and social locale agree.
- Both editions are in the sitemap, with clean slash redirects.
- SEO auditor now checks English for the primary library routes and French for
  the French edition and existing French website, rather than requiring French
  on every public page.
- llms.txt identifies English as primary and links both guides/editions.
