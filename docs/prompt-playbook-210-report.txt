ROUTES AND FEATURES
212 static library pages: /prompts/, /prompts/guide/ and 210 detail routes.
195 new routes beyond the previous 17-page starter library.
Eight cards per page with 27-page catalog navigation and direct page selection.
Search spans full prompt content through a normalized metadata index.
Category, tool, level, theme, favorites and sorting filters retain URL state.
Detail pages restore filters and pagination through a validated return path.
Original/customized/example copy preserves complete multiline content.
Card copy loads only its same-origin static JSON, with retry and error feedback.
Clipboard API, selection fallback and manual-copy dialog are implemented.
Variables with spaces, underscores and repeats are substituted literally; empty
values retain placeholders. Values are neither stored nor sent to an AI API.
Favorites use the existing storage key and degrade safely without storage.
Code blocks, headings, lists and tables are escaped; no arbitrary HTML executes.
Desktop prompt/result panels stack on mobile. Tablet filters collapse above a
wider two-column grid. Creator sections and a ten-section guide are included.
