Understand, build, test

AI Development & Automation

Turn a need into an AI-assisted web application. Learn coding foundations, retrieval from local knowledge and controlled workflows, then test the result before deployment.

Enquire about training ↗WhatsApp ↗

What you will be able to do

  • Read and modify simple Python and JavaScript
  • Use Codex or a similar tool with acceptance criteria
  • Distinguish LLMs, retrieval, agents and workflows
  • Connect an API while protecting data and secrets
  • Test an application and prepare Cloudflare deployment

The programme, module by module

01AI development foundations

LLMs, context, limitations, prompt engineering and evaluation.

Practical exercise
Compare answers with an expected-facts checklist and identify an unsupported answer.

02Python & JavaScript

Variables, functions, objects, JSON, errors and asynchronous calls.

Practical exercise
Transform fictional enquiries into validated objects and test invalid input.

03AI-assisted development

Codex and similar tools: briefs, repository context, bounded changes and review.

Practical exercise
Generate a form, inspect the diff and fix an error with a test.

04Agents, retrieval & workflows

Local sources, passage retrieval, session memory, tools and human approval.

Practical exercise
Build an assistant that cites sources and recognises missing information.

05APIs & AI web applications

HTTP, integrations, input validation, permissions and interface states.

Practical exercise
Connect a demonstration API and simulate network failure without losing user input.

06Testing, security & Cloudflare

Access control, server-side secrets, tests, builds, previews and rollback.

Practical exercise
Prepare a test version, Cloudflare deployment checklist and rollback plan.

Your final project

A concrete, reviewable outcome.

An AI assistant or web application prototype with tests, sources, documented limits and deployment instructions.

Is this track for you?

Audience
Technical beginners, web developers and marketing professionals who want to build AI tools.
Level

Prerequisites
Comfort with files and a browser. A computer that can install development tools; Python and JavaScript foundations are introduced in the programme.
