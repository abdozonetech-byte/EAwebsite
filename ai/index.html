Une conversation sur votre appareil

Le modèle est téléchargé depuis Hugging Face et MLC au premier lancement (environ 1 Go de fichiers, avec environ 2 Go de mémoire GPU requis). Le téléchargement peut prendre plusieurs minutes. Ensuite, les messages sont traités sur votre appareil : aucune API d’inférence externe. Un navigateur compatible WebGPU et suffisamment de mémoire sont nécessaires.

Les fournisseurs de fichiers voient les requêtes de téléchargement, pas votre conversation. L’historique reste uniquement dans cet onglet. Les fichiers du modèle peuvent rester en cache ; effacer les données du site les supprime.

Le modèle n’est pas encore chargé.

L’IA peut se tromper. Vérifiez les pages sources et confirmez les modalités directement avec Abdessamad.
