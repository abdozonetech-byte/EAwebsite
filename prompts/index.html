Mieux demander, mieux vérifier

Un bon prompt est un point de départ.

Ajoutez votre contexte, définissez un résultat vérifiable et contrôlez les sources. L’IA ne remplace pas votre jugement.

  1. Cadrez l’objectif. À qui s’adresse le résultat et à quoi servira-t-il ?
  2. Donnez des limites. Format, ressources, données disponibles, autorisations.
  3. Vérifiez avant d’utiliser. Faits, liens, code, confidentialité et promesses.

Aucune API IA sur cette bibliothèque. Les variables restent dans la page, sans envoi ni sauvegarde. Seuls vos favoris sont conservés sur cet appareil, si le stockage est disponible.
