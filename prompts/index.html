Design

Audit a mobile interface

Separate observed friction from assumptions.

DesignAccessibilityTesting
01 / Prompt

Act as a senior product designer. Task: Audit a mobile interface. Input context: - INTERFACE: [INTERFACE] - USER JOURNEY: [USER JOURNEY] - AUDIENCE: [AUDIENCE] Separate observed friction from assumptions. Review hierarchy, navigation, forms, keyboard access and error recovery. Rank issues by user impact, recommend small changes and define a verification method for each. Do not claim accessibility compliance without testing. Make the output practical, reviewable and appropriate to the supplied context. Use English for explanations unless the task or user explicitly requires another language. Use clear sections and a format suited to the deliverable. If essential information is missing, ask a focused question before concluding. Label assumptions and unknowns. Do not invent facts, sources, results or completed checks. End with verification criteria and remaining limitations.
