Design

Auditer une interface mobile

Identifier les frictions d’un parcours et prioriser des améliorations accessibles.

UXAccessibilitéAudit
01 / Prompt

Agis comme un designer produit. À partir de [DESCRIPTION_INTERFACE], audite le parcours [PARCOURS] pour [PUBLIC]. Sépare observations fournies et hypothèses. Pour chaque friction, précise son impact, une amélioration, une priorité et une méthode de vérification. Analyse navigation, lisibilité, formulaires, erreurs et accessibilité. Si aucune capture ni mesure n’est fournie, ne prétends pas avoir observé l’interface. Termine par trois prochaines actions réalisables.

02 / Exemple illustratif

Réduire les champs indispensables, associer les erreurs aux contrôles et tester le clavier : trois priorités, avec hypothèses et vérifications séparées.

Développer sans régression

Cadrer une fonctionnalité avec un agent de code, sans remplacer l’architecture existante.

CodexClaude CodeTests
01 / Prompt

Tu interviens dans un dépôt existant pour ajouter [FONCTIONNALITE]. Inspecte d’abord les instructions du dépôt, l’architecture, les scripts et les changements locaux. Préserve les modifications existantes. Propose le plus petit changement cohérent, puis implémente-le si tes outils et autorisations le permettent. Ajoute des tests sur [CAS_CRITIQUES]. N’installe pas de dépendances et ne déploie pas sans accord. N’affirme jamais avoir exécuté une commande qui ne l’a pas été. Rapporte fichiers modifiés, vérifications réellement exécutées et limites.

02 / Exemple illustratif

Un plan pour ajouter des favoris locaux : module de stockage protégé, bouton accessible et tests des erreurs, sans réécrire le catalogue.

Apprendre à mieux demander

Un prompt est un début, pas une preuve.

Contexte, format, variables, itération et vérification : découvrez une méthode pratique pour évaluer les réponses.

Lire le guide de prompt engineering ↗
  1. Cadrez la tâche. Résultat, public et contraintes.
  2. Ajoutez votre contexte. Sans secrets ni données inutiles.
  3. Contrôlez la réponse. Sources, hypothèses et tests.

Aucune API IA sur cette bibliothèque. Vos variables restent dans la page sans sauvegarde ni envoi. Seuls les favoris sont conservés localement quand le stockage est disponible.
