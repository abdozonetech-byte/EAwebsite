02 — Example Result

Un exemple concret à examiner.

Exemple rédigé à titre illustratif. Non testé avec un modèle IA ; ce n’est pas un résultat garanti. Il ne change pas avec vos variables.

Plan : ouverture d’un atelier

Instant : une main place un carnet près d’un appareil, vue légèrement plongeante.
Lumière du matin à gauche, profondeur modérée, espace à droite pour le geste suivant.
Invariants : même carnet gris et même table dans la scène suivante. Ratio 16:9 ; détails suffisamment lisibles pour le storyboard.
L’image décrite sert à valider le cadrage, pas à prouver la continuité d’une vidéo encore non produite.

Ce que vous obtenez

Quand l’utiliser

  • Préparer un livrable de storyboard image.
  • Vérifier les décisions liées à : décrire une image de storyboard.

Conseils professionnels

  • Définissez un seul instant par image.
  • Conservez les contraintes utiles lors des itérations.

Erreurs à éviter

  • Décrire plusieurs actions incompatibles dans une même frame.
  • Prendre cet exemple fictif pour un résultat testé ou une preuve réelle.
