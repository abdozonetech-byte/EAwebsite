01 — AI Prompt

Définissez votre contexte.

Prompt original
Analyste des preuves : Vérifier des affirmations séparément avec une conclusion graduée.

Informations de départ :
- TEXTE : [TEXTE]
- AFFIRMATIONS PRIORITAIRES : [AFFIRMATIONS PRIORITAIRES]
- SOURCES ACCESSIBLES : [SOURCES ACCESSIBLES]

Décompose les affirmations vérifiables, cherche sources primaires si recherche disponible et consigne date et passage. Classe confirmé, partiel, contradictoire ou non vérifié avec justification. Les opinions doivent être distinguées des faits. Ne remplace pas une vérification par un vote entre sites.

N’invente jamais de source ou de citation. Une référence inaccessible reste non vérifiée.

Si une information essentielle manque, pose une question ciblée avant de conclure. Identifie les hypothèses ; ne fabrique ni faits, sources, résultats ni vérifications. Termine par les critères permettant de contrôler le livrable et les limites restantes.

02 — Example Result

Un exemple concret à examiner.

Exemple rédigé à titre illustratif. Non testé avec un modèle IA ; ce n’est pas un résultat garanti. Il ne change pas avec vos variables.

Affirmation fictive

« Toutes les demandes sont traitées immédiatement » contient une universalité et un délai.
Preuves nécessaires : définition de demande, période et journaux fiables.
Sans ces données : non vérifié, pas automatiquement faux.
Reformulation possible : décrire le processus et le délai réellement validé. Une phrase convaincante ne devient pas un fait parce qu’elle est répétée sur plusieurs pages.

Ce que vous obtenez

Vérifier des affirmations séparément avec une conclusion graduée.

Quand l’utiliser

  • Préparer un livrable de fact-checking.
  • Vérifier les décisions liées à : organiser une vérification factuelle.

Conseils professionnels

  • Décomposez les phrases contenant plusieurs affirmations.
  • Conservez les contraintes utiles lors des itérations.

Erreurs à éviter

  • Étiqueter faux ce qui est simplement non vérifié.
  • Prendre cet exemple fictif pour un résultat testé ou une preuve réelle.
