01 — AI Prompt

Définissez votre contexte.

Prompt original
Réalisateur audiovisuel : Expliquer un concept en reliant chaque image à une idée.

Informations de départ :
- CONCEPT : [CONCEPT]
- NIVEAU : [NIVEAU]
- DUREE : [DUREE]
- FORMAT : [FORMAT]

Propose objectif pédagogique, analogie limitée, script et storyboard. Introduis une seule notion à la fois ; précise ce que l’analogie ne représente pas. Termine par une question de compréhension. Donne indications de schémas, narration, textes et pauses sans surcharger chaque plan.

Pour chaque plan utile, indique durée, format, composition, caméra, lumière, son et dialogue éventuel. Vérifie les capacités de l’outil ; ne prétends pas avoir produit une vidéo.

Si une information essentielle manque, pose une question ciblée avant de conclure. Identifie les hypothèses ; ne fabrique ni faits, sources, résultats ni vérifications. Termine par les critères permettant de contrôler le livrable et les limites restantes.

02 — Example Result

Un exemple concret à examiner.

Exemple rédigé à titre illustratif. Non testé avec un modèle IA ; ce n’est pas un résultat garanti. Il ne change pas avec vos variables.

Expliquer un webhook — 45 s, 16:9

0–10 s : un formulaire est envoyé ; texte « Un événement se produit ».
10–25 s : flèche vers un serveur ; narration « Un message signale l’événement ».
25–35 s : validation puis action ; distinguer message reçu et action réussie.
35–45 s : question « Que faire si le message arrive deux fois ? »
Fond clair, schémas contrastés, voix posée. L’analogie ne couvre pas tous les mécanismes de sécurité.

Ce que vous obtenez

Expliquer un concept en reliant chaque image à une idée.

Quand l’utiliser

  • Préparer un livrable de explainer.
  • Vérifier les décisions liées à : créer une vidéo explicative.

Conseils professionnels

  • Évaluez ce que le spectateur doit pouvoir expliquer ensuite.
  • Conservez les contraintes utiles lors des itérations.

Erreurs à éviter

  • Multiplier les concepts pour paraître exhaustif.
  • Prendre cet exemple fictif pour un résultat testé ou une preuve réelle.

01 / Prompt

Réalisateur audiovisuel : Créer un concept court avec une promesse claire, sans garantir la viralité. Informations de départ : - SUJET : [SUJET] - AUDIENCE : [AUDIENCE] - DUREE : [DUREE] - FORMAT : [FORMAT] Propose trois angles distincts : question, démonstration et contraste. Pour chaque angle, donne accroche, progression, preuve visible et conclusion. Choisis selon l’objectif et les ressources, puis détaille le meilleur concept en plans.
